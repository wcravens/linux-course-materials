---
title: Writing Markdown
---

Markdown is the plain text format that source repositories, issue trackers,
chat clients, and these course notes are written in. It is a handful of small
conventions: a `#` for a heading, asterisks for emphasis, a hyphen for a list
item. A renderer turns them into HTML or a PDF, and the file stays readable in
a terminal even when nothing renders it. That is why Markdown has become the
default for writing anything that lives alongside code.

This module is a self-contained tour of the format: headings, emphasis, lists
and nesting, links, images, and blockquotes; inline code and fenced blocks with
syntax highlighting; tables, including the caption convention these notes use
so a screen reader announces a table before reading it; the difference between
CommonMark and GitHub Flavored Markdown; and where Markdown turns up on a Linux
system, from `README.md` files to converting documents with `pandoc`.

No prior experience is assumed, and nothing here depends on another lecture.
Read it start to finish in well under an hour, then keep it as a reference. The
fastest way to learn the syntax is to write something in it, so open an editor
and follow along.
