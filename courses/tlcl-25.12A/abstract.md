---
title: The Linux Command Line
---

The command line is the oldest interface Unix offers and still the most
direct. This course follows *The Linux Command Line* by William Shotts
through fourteen meetings, from the first prompt to a working shell script.

We begin with the shell itself — what it is, how it differs from the
operating system underneath it, and how a terminal emulator reaches it. From
there we navigate the filesystem, learn to look at files without changing
them, and then to create, move, and link them. Wildcards and the expansions
the shell performs before a command ever runs get a meeting of their own,
because most early confusion at the prompt is really confusion about who is
interpreting what.

The middle of the course covers the machinery that makes the command line
compose: redirection and pipes, permissions and ownership, processes and
signals, and the environment a shell hands to every program it starts. We
then add the tools that make a working system manageable — package managers,
file search, and archiving — before turning to regular expressions and text
processing.

The last two meetings are shell scripting: scripts, variables, and functions,
then arguments, branching, and keyboard input.

No prior Linux experience is assumed. Every meeting carries notes to read and
a lab to work through at the prompt.
